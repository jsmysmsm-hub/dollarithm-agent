Privacy Policy

Last updated: October 30, 2026

Dollarithm Agent is a private tool run on the owner's own computer. It is used only by the owner, with the owner's own Google account and YouTube channels.

What data the tool accesses

After the owner signs in with Google, the tool uses the YouTube Data API and YouTube Analytics API to read the signed-in channel's statistics and video details, and to edit the metadata of the channel's own videos.

How the data is used and stored

The data is used only to produce reports and to update the owner's own videos. Reports and the sign-in token are stored as files on the owner's computer. No data is sent to any server operated by us, and no data is sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions, and the stored token file can be deleted from the computer.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
